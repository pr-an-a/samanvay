### how · How it works

Target length **28 s** (speech 23.0 s with the Piper voice). Save a human recording as `video/voice/how.m4a`.

1. How it works.
2. First, an AICTE ID match, when both complaints carry one.
3. Without an ID, fuzzy name and address matching, which handles initials and abbreviations.
4. Description similarity tells whether two complaints are about the same issue.
5. Then rule-based clash checks, before an action goes out.
6. Explainable rules, no black-box AI, and a person always decides.
